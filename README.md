# Simple Neural Network Implementation

## 📌 Project Overview

This project demonstrates the implementation of a simple Neural Network using Python and NumPy. It explains how a neural network learns through forward propagation, error calculation, backpropagation, and weight updating.

The model is trained for 5000 epochs to reduce prediction error and improve its learning performance.

## 🎯 Objectives

- Understand the basic working of a Neural Network.
- Implement the Sigmoid Activation Function.
- Perform Forward Propagation.
- Calculate Output Error.
- Implement Backpropagation.
- Update Weights to minimize error.
- Visualize error reduction during training.

## 🛠️ Technologies Used

- Python
- NumPy
- Matplotlib
- Jupyter Notebook

## ⚙️ Concepts Covered

1. **Sigmoid Activation Function:** Converts input values into outputs between 0 and 1.
2. **Forward Propagation:** Passes input data through the network to generate predictions.
3. **Error Calculation:** Calculates the difference between predicted and actual outputs.
4. **Backpropagation:** Calculates gradients to determine how weights should change.
5. **Weight Updating:** Updates weights to reduce prediction error.
6. **Training:** Trains the network for 5000 epochs.

## 📊 Training and Results

The neural network is trained using 5000 epochs. During training, the error gradually decreases, indicating that the model is learning from the input data.

An error graph is plotted to visualize the learning process.
